# 얼굴 회전 실측: 정점, 변환 격자와 잔차

2026-10-23 측정. 원본 MOC를 Cubism Core 6.0.1(Web SDK 5-r.5 배포본)로 평가했다. 모델별 모든 파라미터를 원래 기본값으로 되돌린 뒤 지정 채널만 바꿨다. 물리·모션·시선·표정의 시간 변화는 사용하지 않았다. 정면 재평가의 최대 정점 차이는 두 모델 모두 0이다.

이 문서에는 집계 통계와 해석만 있다. 원본/복원 모델, 텍스처, 정점 좌표, 삼각형 인덱스와 모델을 재현할 수 있는 잔차 필드는 공개하지 않는다. Divina와 Sakura는 각각 해당 제작자의 시험 모델이며, 이 저장소의 자산이 아니다.

## 채널과 범위

| 항목 | Divina | Sakura |
| :--- | :--- | :--- |
| 평가 ArtMesh / 포즈 | 415 / 53 | 503 / 35 |
| 얼굴 X/Y 직접 채널 | ParamAngleXP / ParamAngleYP | ParamAngleX / ParamAngleY |
| 얼굴 Z 직접 채널 | ParamAngleZP | ParamAngleZ |
| 추가 분리 평가 | XP2/YP2, 두 채널군 동시 입력 | 없음 |
| 직접 머리 채널을 가진 Warp 격자 | 23 | 73 |
| XY 포즈 | 각 축 -30,-15,0,15,30의 25개 조합 | 동일 |
| 표준 XYZ 대조와 roll | 각 축 ±30 | 동일 |

Divina 표준 ParamAngleX/Y/Z는 직접 키폼 바인딩이 없고, physics3가 XP/YP/ZP 및 XP2/YP2로 전달한다. 정적 Core에서 표준 채널만 바꾼 결과는 0 변위다. XP2/YP2는 별도의 대상에 연결되므로 얼굴 주 채널과 혼동하지 않는다. 물리 출력 채널에 같은 값을 직접 넣은 실험은 물리의 정상상태나 시간 궤적을 복제한 것이 아니다.

두 모델의 머리 채널 범위는 ±30이다. (30,30)은 파라미터 평면에서 45° 방향인 대각선이며 실제 yaw 45° 포즈가 아니다. 범위 밖 45°를 모델이 지원하는 것처럼 평가하지 않았다.

## 측정값의 의미

최종 SDK 좌표의 y 부호를 뒤집어 화면 아래를 +y로 통일했다. 변위와 오차는 **각 모델 정면 피부 메쉬 폭 W**로 나눈다. 원화 전체나 캔버스 폭 기준이 아니다. 각 영역의 정점에 같은 가중치를 준다. 모델 간 메쉬 밀도 차이는 남아 있다.

아래 X 이동은 X=+30,Y=0의 평균 dx/W, 압축률은 같은 포즈에서 정면→변형 좌표를 최소제곱으로 맞춘 2×2 affine 행렬의 작은 특이값이다. 1은 보존, 0.6은 해당 주축에서 60% 길이다. Y 이동은 X=0,Y=+30의 평균 dy/W다. 대각선 항은 `P(30,30)-P(30,0)-P(0,30)+P(0,0)`의 RMS/W이며 순수 3D 결합항도 포함한다.

눈 좌우는 원본 Part 라벨이다. 화면 좌우 및 두 모델의 명명 방향과 일치한다고 가정하지 않는다. 피부는 중복 그림자 메쉬를 제외한 대표 피부 1개다. 코·입·귀는 얼굴 내 위치, 연결 격자와 부위 그룹으로 식별했다. 눈과 머리카락은 관련 Part 및 자식 그룹을 사용했다. 평상시 숨겨진 스타일 메쉬도 일부 그룹에 포함되므로 이 표는 보이는 픽셀의 면적 통계가 아니다. 모자·장식·몸·워터마크·표정 소품은 부위 비교에서 제외했지만 전체 SDK 샘플에는 보존했다.

## Warp 변환 격자의 로컬 변형

원시 MOC의 rows/columns는 런타임 변환 격자 분할이다. **원래 Editor의 Bezier 손잡이 개수와 같다는 뜻이 아니다.** runtime lattice 좌표와 일반 키폼은 복원되지만 원래 편집 조작 이력은 복원되지 않는다. 공식 문서도 변환 분할과 Bezier 분할을 구분한다. [Warp Deformer](https://docs.live2d.com/en/cubism-editor-manual/making-and-placement-of-warp-deformer/).

로컬 격자는 각 객체의 부모 좌표계에서 측정했다. 아래 RMS는 그 격자의 정면 최대 축 길이 L로 정규화했다. 서로 다른 격자의 로컬 단위를 바로 비교하지 않는다. shear는 affine 극분해의 대칭 stretch 행렬 비대각값이다. 곡률 변화 지표는 정면 대비 격자 2차 차분 변화의 RMS/L이며 3D의 미분기하 곡률이 아니다. 부모 변환·blendshape·quad 평가·glue가 반영된 최종 위치는 위 SDK ArtMesh 측정값을 사용한다.

Divina의 피부 하위 Warp19는 머리 축에 묶여 있어도 자체 격자 변화가 거의 0이며 상위 Warp20 등의 변형을 상속한다. 모든 이동을 최하위 격자의 키폼으로 설명하면 이 부분을 놓친다. 코 격자는 폭이 작은 로컬 L로 나누므로 정규화 이동량이 1을 넘을 수 있다.

Sakura의 상위 Warp20은 단독 X, 단독 Y에서 저장된 격자가 정확히 동일하다. (+30,+30)에서만 RMS/L=0.02528의 변형을 낸다. 이 모델에는 축별 변위 합성으로 얻을 수 없는 대각선 전용 보정이 실제 저장돼 있다. 다른 격자의 대각선 항까지 모두 수작업으로 만들었다는 뜻은 아니다.

## Roll과 목

+30에서 피부의 실제 강체 회전은 Divina 15.8°, Sakura 15.0°다. 얼굴·이목구비는 affine 비강체 잔차가 수치 정밀도 수준이다. Divina의 Rotation3 blend row에도 +15.8°가 저장돼 있다. 목은 같은 포즈에서 affine 회전 추정값 8.31°와 5.29°이고, 비강체 RMS는 각각 1.77%W, 1.84%W다. 이 각도는 목 전체 affine 근사값이며 목에 실제 강체 회전이 하나 적용됐다는 뜻이 아니다.

Divina의 roll은 Warp37, 목 ArtMesh352와 두 rotation target에 blend row가 있다. 이 네 바인딩의 constraint 목록은 비어 있다. 따라서 roll에서 목의 직접 메쉬 변형과 머리 회전이 별도 경로로 존재한다. Sakura의 목 Warp58은 Z 채널 전용이고 XY에서는 목의 최종 정점 변위가 0이다.

## 위쪽 머리와 턱, 메쉬 품질

두 모델의 Part 이름만으로 정수리를 독립적으로 확정할 수 없어, 관련 앞·옆·뒷머리 정점 중 피부 bbox 상단 20% 높이보다 위에 있는 정점들을 `upper_hair_band`로 따로 측정했다. 이 공간 대역은 위의 머리카락 그룹과 겹치는 보조 진단이며 독립 파츠를 새로 복원한 것이 아니다. 턱도 피부 하단 15% 정점 대역으로 별도 측정했다. 전체 목록과 정점별 변위는 비공개 측정 산출물에 남긴다.

Divina: 위쪽 머리 1616정점, X 평균 이동 17.63%W, 작은 주축 비 0.906. 턱 대역 68정점, X 평균 이동 18.35%W, 작은 주축 비 0.725. 대각선 피부 삼각형 448개에서 뒤집힘 0개, 면적비 5/50/95백분위 0.393, 1.177, 1.894.

Sakura: 위쪽 머리 1490정점, X 평균 이동 6.90%W, 작은 주축 비 0.843. 턱 대역 147정점, X 평균 이동 10.66%W, 작은 주축 비 0.755. 대각선 피부 삼각형 1242개에서 뒤집힘 0개, 면적비 5/50/95백분위 0.507, 0.770, 1.300.

## 3D 기준 + 9키 잔차의 중간 포즈 검증

구 중심은 피부 bbox 중심, 반지름은 최대 bbox 축 길이의 0.6배로 두고 파라미터를 그대로 도 단위 각도로 사용한 **고정 초기 기준**이다. 뒷머리는 뒤쪽 hemisphere 부호를 사용했다. 나머지는 앞쪽이다. 이는 형상을 맞춘 최적 구면과 다르며, 안구 자식 구의 크기·깊이를 추정한 실험도 아니다. 목에 머리 회전을 적용한 기준은 오류 진단용이고 실제 목 설계에서는 몸 고정 부착을 사용한다.

9개 격자 키에서 잔차를 계산하고, 그 9개를 제외한 16개 중간 포즈의 모든 해당 정점을 평가했다. 공개 `head-turn.mjs`를 실제로 호출했다. 모델 정점·필드는 비공개 입력이며 공개 코드에 내장하지 않았다.

긴 뒷머리에는 7.49%W까지 남는다. 고정된 머리 구와 9개 잔차만으로 모든 머리카락을 완성했다고 볼 수 없다. 양쪽 눈의 국소 압축, 긴 머리의 독립 회전·스키닝·glue, 피부 윤곽과 목 부착을 각 소유자에서 다뤄야 한다. 실제 원화 렌더의 심미성과 가림·색 번짐은 이 좌표 오차만으로 판정하지 않았다.
